# ID46053_R5_5Story_v.02 — OpenSees RC Frame Model (SPO / IDA / MSA)

2D nonlinear OpenSees model of a **5-storey, 4-bay RC special moment frame (R = 5)**, designed to the
IS 1893 (2025) update. It is used for:

- **SPO**: static pushover (monotonic, optionally cyclic)
- **IDA**: incremental dynamic analysis
- **MSA**: multiple stripe analysis

**Units:** kN, mm, seconds.
**Lineage:** C. B. Haselton (Stanford, 2005), modified by P. S. Badal (IIT Bombay, 2016) and by Shivakumar K S (IIT Madras, 2025–26).

This README covers the 22 `psb_*.tcl` files in this folder. It also explains how to make a new model
folder from this one, for example **ID46053 → ID35053**.

---

## 1. Folder layout

```
ida-spo-msa/
├── psb_MasterDriver_ProcPushoverAnalyses.m        <- MATLAB driver: SPO
├── psb_MasterDriver_RunNProcDynAna_<ID>v02.m      <- MATLAB driver: IDA/MSA (one per model)
├── OpenSeesProcessingFiles/EQs/                   <- ground motions (DtFile_, NumPointsFile_, SortedEQFile_)
└── Models/
    ├── VBA_MODEL_FILES/                           <- Excel design sheets (.xlsm) that generate the model code
    ├── psb_Sensitivity_Analysis/                  <- MATLAB IDA/MSA runner (writes psb_VarDefinitionsFromMATLAB.tcl)
    ├── ID2433_R5_5Story_v.02/
    ├── ID35053_R5_5Story_v.02/
    └── ID46053_R5_5Story_v.02/                    <- THIS FOLDER
        ├── psb_*.tcl                              <- 22 master .tcl files (edit these)
        ├── model_<eqNumber>/                      <- per-record copies (auto-generated, do NOT edit)
        └── README.md
```

> **`model_<eqNumber>/` folders are auto-generated.** Before an IDA/MSA run,
> `psb_RunCollapseAnaMATLAB_NEWER_proc.m` copies every `*.tcl` in this folder into one
> `model_<eqNumber>` folder per ground motion, so the records can run in parallel (`parfor`).
> Always edit the `.tcl` files in the **root of the model folder**. Any edit made inside a
> `model_*` folder is overwritten on the next run. To force fresh copies, delete the `model_*`
> folders.

## 2. What each `.tcl` file does

The entry file is **`psb_RunMeanAnalysis.tcl`** for SPO. For IDA/MSA, MATLAB writes its own driver
that sources the same files.

| # | File | Role |
|---|------|------|
| 1 | `psb_RunMeanAnalysis.tcl` | **Root file for SPO.** Sets `analysisMode Pushover`, then sources everything below in order. |
| 2 | `psb_DefineUnitsAndConstants.tcl` | Units and constants (g, π, …). |
| 3 | `psb_DefineVariablesAtMeanValues.tcl` | Mean material/model variables: damping ratio, **Rayleigh periods**, Ibarra hinge parameters (`c`, `resStrRatio`, `stiffFactor1/2`), etc. |
| 4 | `psb_DefineFunctionsAndProcedures.tcl` | Tcl procs (`CreateIbarraMaterial`, joint and hinge builders, EQ time-series loading via `$eqDataFolder`). |
| 5 | `psb_SetAnalysisOptions.tcl` | **Model name**, which analyses to run, max pushover displacement, solver options, recorder switches. |
| 6 | `psb_SetUpModel.tcl` | `model BasicBuilder -ndm 2 -ndf 3`, geomTransf, extra materials. Sources the VBA model code and the gravity analysis. |
| 7 | `psb_ModelCodePastedFromExcelVBA.tcl` | **The building itself:** nodes, elements, hinges, joints, masses, loads, damping, recorder lists. Generated by the Excel/VBA sheet. |
| 8 | `psb_PeformGravityLoadAnalysis.tcl` | Gravity load analysis. |
| 9 | `psb_WriteNeededInformationToFilesForMatlab.tcl` | Writes model information (nodes, floors, periods) for MATLAB post-processing. |
| 10 | `psb_RunPushoverIfSpecified.tcl` | Runs the monotonic pushover if `runPushover YES`. |
| 11 | `psb_DefinePushoverLoading.tcl` | **Lateral load pattern** for pushover (node forces per floor). Generated by Excel/VBA. |
| 12 | `psb_RunPushoverLoading.tcl` | Displacement-controlled pushover loop. |
| 13 | `psb_RunCyclicPushoverIfSpecified.tcl` | Runs the cyclic pushover if `runCyclicPushover YES`. |
| 14 | `psb_RunCyclicPushoverLoading.tcl` | Cyclic pushover loop. |
| 15 | `psb_DefineAllRecorders.tcl` | Node, element, joint and hinge recorders. Full set for Pushover, limited set for IDA/MSA. |
| 16 | `psb_DefineEarthquakeRecordInformation.tcl` | Ground motion database metadata. |
| 17 | `psb_SolutionAlgorithmSubFile.tcl` | Convergence and solution-algorithm fallback sequence. |
| 18 | `psb_SaveRunInformationAfterEQ.tcl` | Saves run information after each EQ. |
| 19 | `psb_SaveRunInformationAfterEQForCollapse.tcl` | Same, for collapse (IDA) runs. |
| 20 | `psb_RedefineEverythingAndReSetUpModel.tcl` | Re-sources definitions and rebuilds the model (used between runs). |
| 21 | `psb_RedefineEverythingAndReSetUpModelColSENSITIVITYMATLAB.tcl` | Same, for MATLAB collapse/sensitivity runs. |
| 22 | `psb_RunSingleColRecordSensMATLAB.tcl` | Runs one record at one Sa level (called from MATLAB for IDA/MSA). |

## 3. Creating a new model from this one (e.g. ID46053 → ID35053)

The comparison below was made by running a file-by-file diff of all 22 `.tcl` files in
ID46053 against ID35053 and ID2433.

### 3.1 Common files: copy as-is, no change needed

These 17 files are **byte-identical** in ID46053 and ID35053. They contain no building-specific data.

| File | Note |
|------|------|
| `psb_DefineEarthquakeRecordInformation.tcl` | |
| `psb_DefineFunctionsAndProcedures.tcl` | ⚠ ID2433 has an **older** version with hard-coded `C:/Users/...` EQ paths. Use this one, which reads from `$eqDataFolder`. |
| `psb_DefineUnitsAndConstants.tcl` | |
| `psb_DefineVariablesAtMeanValues.tcl` | ⚠ Identical file, but see **§3.3**: the Rayleigh damping periods should be checked for each building. |
| `psb_PeformGravityLoadAnalysis.tcl` | |
| `psb_RedefineEverythingAndReSetUpModel.tcl` | |
| `psb_RedefineEverythingAndReSetUpModelColSENSITIVITYMATLAB.tcl` | |
| `psb_RunCyclicPushoverIfSpecified.tcl` | |
| `psb_RunCyclicPushoverLoading.tcl` | |
| `psb_RunPushoverIfSpecified.tcl` | |
| `psb_RunPushoverLoading.tcl` | |
| `psb_RunSingleColRecordSensMATLAB.tcl` | |
| `psb_SaveRunInformationAfterEQ.tcl` | |
| `psb_SaveRunInformationAfterEQForCollapse.tcl` | |
| `psb_SetUpModel.tcl` | |
| `psb_SolutionAlgorithmSubFile.tcl` | |
| `psb_WriteNeededInformationToFilesForMatlab.tcl` | |

### 3.2 Files that must change

Only **2 files** hold the building itself. They are generated by the Excel/VBA design sheet in
`Models/VBA_MODEL_FILES/`. Replace them completely with the output for the new building.

| File | Replace with | What changes |
|------|--------------|--------------|
| `psb_ModelCodePastedFromExcelVBA.tcl` | The VBA output of the **new building's** sheet, e.g. `35053v05_20260313General Excel Sheet 2016.xlsm` | Joint panel materials, Ibarra hinge properties (EIeff, My, θcap, θpc, λ), nodes, elements, masses, loads, damping block, `poControlNodeNum`, and the recorder lists (`elementNumToRecordLIST`, `nodeNumToRecordLIST`, `columnNumsAtEachStoryLIST`, `floorHeightsLIST`, `nodeNumsAtEachFloorLIST`, …). |
| `psb_DefinePushoverLoading.tcl` | The pushover pattern exported from the **same** sheet | `load <node> <Fx> 0 0` lines in `pattern Plain 13 Linear { … }`. Lateral force distribution per floor and column line (nodes 202xx3–206xx3). |

One more file needs a **one-line edit**:

| File | Line to edit | ID46053 value | Example for ID35053 |
|------|--------------|---------------|---------------------|
| `psb_SetAnalysisOptions.tcl` | `set model …` (≈ line 26) | `set model ID46053_R5_5Story_v.02` | `set model ID35053_R5_5Story_v.02` |
| `psb_SetAnalysisOptions.tcl` | `set maxPushoverDisp …` (≈ line 63) | `1500.0` (IS 1893:2025 models) | `720.0` (IS 1893:2016 models) |

> `set model` **must equal the folder name** exactly. It sets the output folder name
> `(<model>)_(AllVar)_(0.00)_(clough)`, and the MATLAB drivers look for that name.

### 3.3 Check for each building (common file, but values are building-dependent)

| File | Item | Current value |
|------|------|---------------|
| `psb_DefineVariablesAtMeanValues.tcl` | `periodForRayleighDamping_1` (mode-1 period) | `1.84` s |
| `psb_DefineVariablesAtMeanValues.tcl` | `periodForRayleighDamping_2` (mode-3 period) | `0.34` s |
| `psb_DefineVariablesAtMeanValues.tcl` | `dampRat` | `0.05` |

These periods set the Rayleigh damping coefficients in the VBA model code. The source comment says
"NEEDS to be UPDATED". They are currently the same in all three models. Run the eigen analysis
(`runEigenAnalysisForMatlab 1`) for the new building and update them if they differ.

### 3.4 Version note: ID35053 is behind ID46053

Three more files differ between ID46053 and ID35053. The differences are **not** building data:
ID46053 has the **24-Sep-2026 recorder-control update** and ID35053 does not.

| File | Change in ID46053 |
|------|-------------------|
| `psb_RunMeanAnalysis.tcl` | Adds `set analysisMode Pushover`. |
| `psb_SetAnalysisOptions.tcl` | Picks full or limited recorders from `analysisMode` (Pushover → full, IDA/MSA → limited). |
| `psb_DefineAllRecorders.tcl` | Defines element local/global force recorders only in Pushover mode, to save disk space in IDA/MSA. |

**Recommendation:** when building any new model, start from **these ID46053 files** and change only
what is listed in §3.2 and §3.3. To bring ID35053 or ID2433 up to date, copy these three files from
ID46053 and then re-apply their `set model` and `maxPushoverDisp` lines.

### 3.5 Step-by-step checklist

1. Copy `ID46053_R5_5Story_v.02/` to `<NewID>_R5_5Story_v.02/`. Copy only the `psb_*.tcl` files and this README, **not** the `model_*` folders.
2. Replace `psb_ModelCodePastedFromExcelVBA.tcl` with the new building's Excel/VBA output.
3. Replace `psb_DefinePushoverLoading.tcl` with the new building's pushover pattern.
4. In `psb_SetAnalysisOptions.tcl`, set `set model <NewID>_R5_5Story_v.02` and check `maxPushoverDisp`.
5. In `psb_DefineVariablesAtMeanValues.tcl`, check `periodForRayleighDamping_1/2` (§3.3).
6. Update the MATLAB driver(s) in the repository root (see §4).
7. Run SPO first as a sanity check. Then run IDA/MSA.

## 5. How to run

### Requirements

- OpenSees (Tcl interpreter) on the system `PATH`
- MATLAB with the Parallel Computing Toolbox (for `parfor` in IDA/MSA)
- Ground motion files in the `EQs` folder, and `SaEQSpectrum_EQ_<n>.mat` spectra in `EQ_Spectra_Saved`

### Static pushover (SPO)

From MATLAB, in the repository root:

```matlab
psb_MasterDriver_ProcPushoverAnalyses   % runs OpenSees psb_RunMeanAnalysis.tcl, then plots
```

Or directly in this folder:

```bash
OpenSees psb_RunMeanAnalysis.tcl
```

For a pushover, `psb_SetAnalysisOptions.tcl` must have `set runPushover YES`.

### IDA / MSA

From MATLAB, in the repository root:

```matlab
psb_MasterDriver_RunNProcDynAna_46053v02   % choose IDA_or_MSA and the eqNumberLIST inside
```

> At the time of writing, only an autosave (`psb_MasterDriver_RunNProcDynAna_46053v02.asv`) exists
> for ID46053. Copy `psb_MasterDriver_RunNProcDynAna_35053v02.m` to a new name and change the
> variables listed in §4.

MATLAB will:

1. Create the `model_<eqNumber>` folders and copy `*.tcl` into them.
2. Write `psb_VarDefinitionsFromMATLAB.tcl` with `eqNumber`, the scale factor, `eqDataFolder` and `analysisMode IDA`.
3. Run OpenSees in parallel, one record per worker.

### Output

Results are written to `ida-spo-msa/Output/(<model>)_(AllVar)_(0.00)_(clough)/…`

## 7. Notes and gotchas

- **Do not edit files inside `model_*/`.** They are overwritten on every run.
- `set model` in `psb_SetAnalysisOptions.tcl` must match the folder name, or the output will go to the wrong folder.
- `displayMode "displayON"` opens a graphics window. Set it to `"displayOFF"` for batch or cluster runs.
- The `others/` folder (ID2433 linear/parabolic) holds experimental variants and is not part of the main workflow.
- `psb_Sensitivity_Analysis/` contains several versions of the runner (`_OLD_v0`, `_v2`, `_v3`). The active one is `psb_RunCollapseAnaMATLAB_NEWER_proc.m`.

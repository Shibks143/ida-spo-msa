(1/4) Prepare the excel file with inputs for GM selection.

(2/4) Run the app NBCC_GroundMotionSelectionAPP.mlapp
Change the excel file name, if needed. 
Click on "Read Table". Edit values, if needed.
Edit Results Directory Name, if default name is not desired.
Click on "Select Ground Motion Records"

Selected GM records are populated in the table on top right box of the app.

(3a/4) Download NGA-W2 records from https://ngawest2.berkeley.edu/ or 
(3b/4) Download KiK-net records using the script in GMSelection_DownloadData or directly from https://www.kyoshin.bosai.go.jp/kyoshin/search/index_en.html

(4/4) Save the records in the "GMSelection_format" directory. Use the app there.
